# Виправити спільне відображення рейтингів

## Що зміниться
- Розширити `Scoreboard`, щоб на тижневому перегляді одночасно показувався окремий блок загального рейтингу студента.
- Залишити перемикач «Тиждень / Загальний»: він керує основним списком, але не приховує додатковий загальний результат у тижневому стані.
- Додатковий блок матиме місце, бали, підсвічення поточного студента, loading та відсутній стан без стрибків сторінки.
- Оновити демонстрацію, публічний API, документацію та приклад інтеграції для LMS.

## Технічні деталі
- Додати до `Scoreboard` типізований проп для супутнього рейтингу з назвою, періодом і рядком поточного студента.
- Компонент залишиться презентаційним: LMS передає тижневі та загальні значення з власних запитів.
- Зберегти зворотну сумісність чинних `periods`, `activePeriod`, `rows` і `currentRow`.
- Перевірити стани: завантаження, 0 балів / `rank = null`, студент у списку й поза ним, мобільний та desktop вигляд.
